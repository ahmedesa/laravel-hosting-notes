About

Hi, I'm Ahmed Esa. I'm a senior backend developer and I've been writing PHP for years, most of it with Laravel. My day job is building APIs, queues, and the boring-but-important parts of web apps that need to keep running.

This site is where I write down what I've learned about hosting and deploying Laravel: which kinds of hosts work, which don't, and the exact commands I use to get an app into production. If a guide here doesn't work for you, I want to know about it so I can fix it.

How I write these

  • I cover trade-offs, not just the good parts.
  • I don't paste prices or benchmarks I can't back up. Prices change often, so check the provider's site before you buy.
  • Some links are affiliate links. See the disclosure for how that works.
